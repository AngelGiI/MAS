# Multi-Agent Systems: Final Assignment

This repository contains the final assignment for the **Multi-Agent Systems** course, focusing on Monte Carlo simulations and reinforcement learning techniques to solve practical problems.

---

## Overview

### **Monte Carlo Simulation: Optimal Batch Testing**
- **Objective**: Optimize batch testing for a hypothetical pandemic scenario using Monte Carlo simulations.
- **Key Highlights**:
  - Derived the optimal batch size to minimize testing resources.
  - Achieved up to **98% workload reduction** for low infection probabilities.

### **Reinforcement Learning: Cliff Walking**
- **Objective**: Solve the cliff-walking problem using SARSA and Q-Learning algorithms.
- **Key Highlights**:
  - Compared SARSA (on-policy) and Q-Learning (off-policy) policies for safe vs. optimal paths.
  - Experimented with epsilon-greedy policies and replay buffers to improve learning stability.

- **`README.md`**: This file.
